# 易经六爻 AI 占卜 · 简易版(MVP)

最小可用版本：输入问题 → 摇卦(按钮) → 出本卦 → Kimi 结合问题解读。
摄像头、呼吸动画、铜钱动画、变卦展示等留待后续迭代。

## 文件说明
- `server.js` — 后端：起卦算法 + 查卦 + 调用 Kimi（密钥在此安全读取）
- `public/index.html` — 前端：占卜页面
- `hexagrams.json` — 64 卦数据（已修正兑为泽的 bug）
- `hexagram_lookup.json` — 爻象编码 → 卦号 查找表

## 运行步骤
1. 安装依赖：
   ```
   npm init -y
   npm install express
   ```
2. 设置你的 Kimi 密钥（换成你新生成的那个，别写进代码）：
   - Mac/Linux： `export MOONSHOT_API_KEY=你的密钥`
   - Windows(PowerShell)： `$env:MOONSHOT_API_KEY="你的密钥"`
3. 启动： `node server.js`
4. 浏览器打开： http://localhost:3000

## 安全要点
- 密钥只放在环境变量里，绝不写进代码、绝不出现在前端。
- 前端只调用本地 `/api/divine`，由后端去请求 Kimi，浏览器看不到密钥。

## 起卦逻辑（三铜钱六爻法）
- 每爻抛三枚铜钱：字面记2、背面记3（一种常见约定，可调换）
- 三枚之和 6/7/8/9 → 老阴/少阳/少阴/老阳
- 抛6次自下而上成本卦；老阴(6)、老阳(9)为变爻，翻转得变卦
- 算法已通过测试：64卦全覆盖、变卦正确
